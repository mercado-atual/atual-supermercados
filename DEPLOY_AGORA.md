# 🚀 Deploy Rápido - 3 Comandos!

## ⚡ Método Mais Rápido (CLI)

Já instalei a CLI do Vercel para você! Agora só precisa fazer login e deploy:

### Passo 1: Login no Vercel
```bash
vercel login
```
- Vai abrir o navegador
- Faça login com sua conta GitHub
- Autorize o acesso

### Passo 2: Deploy
```bash
vercel --prod
```
- Responda as perguntas:
  - **Link to existing project?** → **N** (não)
  - **What's your project's name?** → **projeto-atual** (ou pressione Enter)
  - **In which directory is your code located?** → **./** (pressione Enter)
  - **Want to override the settings?** → **N** (não)

### Passo 3: Pronto!
Você receberá uma URL como:
```
https://projeto-atual.vercel.app
```

## 🌐 Método Alternativo (Interface Web)

Se preferir usar a interface web:

1. **Acesse**: https://vercel.com/new

4. **Deploy** (não precisa mudar nada)
